# Changelog

All notable changes to this project are documented in this file.

The format follows Keep a Changelog, and this project uses Semantic Versioning.

## [0.1.0] - 2026-08-19

### Added

- Initial read-only Windows blue screen diagnostic collection tool.
- BugCheck, Kernel-Power, unexpected shutdown, WHEA, GPU, and storage event collection.
- System, CPU, motherboard, BIOS, memory, GPU, disk, PnP, dump configuration, and dump evidence collection.
- Minidump listing and copy of the latest five minidumps into the local report directory.
- Local init, test, build, clean, and package automation.
- Windows PowerShell 5.1 GitHub Actions CI workflow.
